# SEIS GitHub Context

## GitHub operating layer
- Keep `SEIS` docs, governance, roadmap and PR evidence coherent.
- Branch model follows `06_GitHub/Branch Strategy.md`.
- Do not claim readiness without checks and explicit blocker list.
- PRs should keep user files intact and avoid unrelated rewrites.
