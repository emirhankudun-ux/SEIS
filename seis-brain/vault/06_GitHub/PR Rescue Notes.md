# PR Rescue Notes

## Purpose
Failed or blocked PR sonrası güvenli kurtarma akışı.

## Entry format
- PR context
- Failure evidence
- Minimal safe fix
- Validation status
- Next owner

## Rules
- Do not erase evidence.
- Prioritize minimal safe corrections.
- Close only after risk list is explicit and checks are honest.
