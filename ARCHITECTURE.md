# SEIS Architecture

## Purpose

This root pointer gives agents and contributors a stable architecture entry
point without duplicating the canonical architecture docs.

## Current Status

SEIS architecture is documented across focused docs. The repository is not
claiming that every planned Command Center, Desktop, AI Core, model-router,
agent-runtime, SSH, cloud, or release system is implemented.
