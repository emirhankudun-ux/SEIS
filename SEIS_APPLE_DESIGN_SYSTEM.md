# SEIS Apple Design System

The SEIS Apple design system combines Apple-level interaction discipline with
SEIS cinematic identity.

## Principles

- clarity before decoration
- strong spacing
- readable hierarchy
- clean sidebars
- clear toolbars
- native-feeling controls
- content-first panels
- command-first workflows
- keyboard-first shortcuts
- restrained motion
- accessible contrast
- reduced-motion support

## Visual Direction

Use deep black, graphite, charcoal, warm gray, and off-white as the stable base.
Use electric cyan for precise accents, soft violet for secondary accents, amber
for warnings or highlights, green for healthy status, and red only for critical
warnings.

## Components

Apple-native SEIS surfaces should converge on:

- sidebar navigation
- toolbar search and command palette
- status pills
- module cards
- inspector panels
- readiness rows
- provider metadata cards
- agent report cards
- safe-command checklists
- public/private visibility badges

## Motion

Motion should be calm and structural. Avoid constant animated UI. Respect
reduced motion, keep transitions short, and never use animation to hide unclear
layout.

## Icons

Use semantic, system-compatible icon names in SwiftUI. Avoid requiring custom
copyrighted Apple assets. Icons should clarify action or state, not decorate.

## Accessibility

Every native surface should support VoiceOver-friendly labels, Dynamic Type
where applicable, sufficient contrast, keyboard navigation, visible focus, and
reduced motion.
