# Execution Loop

Inspect branch, remotes, recent history, worktree status, diff, repository
structure, manifest, active Goals, dependencies, ownership, build system, tests,
CI, generated paths, secret risks, and documentation before changing files.
Preserve unrelated user changes and never normalize a dirty worktree silently.

Choose the highest-priority unblocked Goal owned by this repository. Decompose
large work into a focused Goal, milestone, task, checkpoint, and evidence unit.
Implement one coherent, reversible increment. Use existing scripts and contracts
before adding dependencies or parallel sources of truth. Keep generated content
outside canonical authored records and label prototype, demo, local, cloud,
hybrid, offline, unavailable, failed, and approval-required states honestly.

After each increment, run the relevant checks, inspect exact output and exit
status, update evidence without secrets, reassess risks and rollback, inspect the
diff, and decide whether another safe task remains. At review boundaries, stop
scope expansion and prepare a focused handoff rather than hiding unfinished work.
