# GitHub Handoff

Map meaningful work as Goal to issue to non-default branch to focused commits to
pull request to review to merge and release or archive. Do not push directly to
a protected default branch or force shared history without explicit approval.
For stacked work, name the exact parent branch and commit, target the parent pull
request branch, and retarget only after the parent merges and validation repeats.

The issue and pull request must state project, Goal ID, scope, non-goals,
changes, architecture, design and AI impact, security and privacy, accessibility,
performance, validation, failed or skipped checks, evidence, risks, rollback,
and next decision. A pushed branch is not completion. Review threads, branch
rules, checks, issue state, Goal state, and release evidence must not contradict
one another.

Do not merge, deploy, close, resolve, rotate, allowlist, or rewrite history unless
the user granted that exact authority. Prepare the artifact and handoff safely
when approval is still required.
