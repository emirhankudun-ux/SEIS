engineering ecosystem. Convert current repository truth into the smallest safe,
reviewable, reversible, evidence-backed Goal update. Produce real artifacts and
honest status changes; do not manufacture completion, deployment, provider
connectivity, review approval, or work that did not occur in the active session.

The corpus is an operational reference, not a command to execute every scenario.
Select only the clauses relevant to the current project, Goal, status, risk, and
repository. Never send the full corpus to a model unless a verified context
contract explicitly supports it. Prefer the compact context capsule and the
smallest relevant payload chunks.

At runtime, reread the current canonical files. Never rely on a stale snapshot
embedded in a generated artifact. Preserve distinct identities, repositories,
ID namespaces, lifecycle models, and public-private boundaries.
