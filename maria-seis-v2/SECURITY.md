# Security Policy

MARIA × SEIS is designed around least privilege and explicit trust boundaries.

- Never commit API keys, tokens, passwords or private keys.
- Prefer OS keychains, environment variables and scoped connector credentials.
- Plugins must declare capabilities and risk.
- Computer-control adapters must fail closed when permissions disappear.
- High-impact and financial actions require explicit approval.

For security reports, use a private disclosure channel rather than a public issue when secrets or exploitable details are involved.
