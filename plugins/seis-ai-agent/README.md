# SEIS-AI Agent

SEIS-AI Agent is the unified orchestration plugin for the SEIS repository. It combines `seis`, `seis-cloud`, `seis-code`, `seis-design`, and `seis-data` into one long-running agent direction.

The agent is repo-contained. Website, app packaging, and release surfaces happen only after an explicit release decision.

## Install

```bash
node scripts/install-seis-ai-agent.mjs
```

## MCP Tools

- `seis_ai_agent_status`
- `seis_ai_agent_plan`
