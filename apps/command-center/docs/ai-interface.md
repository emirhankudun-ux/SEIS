# AI Interface

Status: App-facing contract

The AI interface exposes SEIS AI Core safely inside Command Center.

## Requirements

- show model route and privacy mode
- show data mode and LLM execution mode
- show prompt or behavior version when relevant
- show context and memory status
- block privileged actions until approved
- link claims to evidence
- show degraded and unknown states honestly
