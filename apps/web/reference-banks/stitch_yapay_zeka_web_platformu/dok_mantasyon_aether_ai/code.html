Quickstart Guide

1

Install the Aether SDK

Bootstrap your environment by installing the core package via your preferred package manager.

terminal
npm install @aether-ai/core-sdk --save-dev
2

Initialize the Client

Create a secure instance using your secret keys. Ensure these are stored in environment variables.

typescript 
import { AetherClient } from '@aether-ai/sdk';

// Initialize with hardware-acceleration
const client = new AetherClient({
  apiKey: process.env.AETHER_API_KEY,
  region: 'us-east-shred',
  acceleration: 'h100-tensor'
});
3

Run Your First Inference

Invoke the prediction engine. Response streams are supported via standard Web Streams API.

typescript 
const response = await client.inference.predict({
  model: 'aether-titan-v3',
  prompt: 'Synthesize a reactive UI kernel...',
  temperature: 0.7
});

// Process the high-dimensional vector output
console.log(response.vectors);
