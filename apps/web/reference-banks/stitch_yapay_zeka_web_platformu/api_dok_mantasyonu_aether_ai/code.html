API Documentation

Welcome to the Aether AI API reference. Our API is organized around REST. All requests should be made to https://api.aether.ai/v1. Our API has predictable resource-oriented URLs, accepts form-encoded request bodies, returns JSON-encoded responses, and uses standard HTTP response codes, authentication, and verbs.

info

Looking for our SDKs? Check out our Node.js, Python, and Go libraries.

Authentication

The Aether AI API uses API keys to authenticate requests. You can view and manage your API keys in the Aether Dashboard.

Your API keys carry many privileges, so be sure to keep them secure! Do not share your secret API keys in publicly accessible areas such as GitHub, client-side code, and so forth.

Authorization: Bearer AETHER_API_KEY

Rate Limits

Rate limits are enforced per organization. If you exceed the rate limit, the API will return a 429 Too Many Requests error.

Create Completion

/v1/completions

Creates a completion for the provided prompt and parameters. Our inference engine optimizes the request for the fastest token generation possible.

Body Parameters

model string

ID of the model to use. You can use aether-1-pro.

REQUIRED
prompt string

The prompt(s) to generate completions for.

REQUIRED
temperature float

Controls randomness. Higher values mean more random outputs.

OPTIONAL 
curl https://api.aether.ai/v1/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $AETHER_API_KEY" \
  -d '{
    "model": "aether-1-pro",
    "prompt": "Describe the future of computing.",
    "max_tokens": 250,
    "temperature": 0.7
  }'
Example Response
