# SEIS WOW More Pages — Part 3

This package adds 24 more SEIS OS screens to the previous visual packages.

## Contents

- `png/` — 24 PNG visual references
- `html/` — 24 editable HTML pages
- `assets/css/seis.css` — shared visual system
- `assets/js/seis.js` — basic interaction layer
- `index.html` — gallery index
- `CODEX_IMPLEMENTATION_PROMPT_PART3.md` — Codex instructions

## Preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173/index.html
```
