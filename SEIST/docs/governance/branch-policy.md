# Branch Policy

## Main Branch

Main is sacred. It should only receive reviewed, reversible, meaningful changes.

## Recommended Branches

| Branch | Purpose |
| --- | --- |
| `chore/seis-foundation-audit` | reports, asset registry, foundation shell |
| `feature/curated-archive` | migrated artwork and metadata |
| `feature/cinematic-hero` | 3D/canvas hero experiments |
| `feature/mobile-pwa` | manifest, mobile polish, offline strategy |

## Commit Size

Prefer small commits:

- docs and policy
- asset registry
- web shell
- quality scripts
- selected assets

Avoid mixing extracted legacy dumps with app code.
