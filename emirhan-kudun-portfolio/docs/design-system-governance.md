# Design System Governance

The SEIS portfolio should stay cinematic without becoming visually loud.

## Interface Rules

- Use large editorial type only where the page has enough space to breathe.
- Keep runtime cards compact and factual; status labels should be easier to scan than paragraphs.
- Prefer restrained contrast, visible focus states, and 44px minimum interactive targets.
- Respect reduced-motion preferences and avoid decorative motion that does not clarify the interface.

## Growth Rules

- Add new sections through shared content or runtime registries first.
- Keep the homepage curated; move dense operational surfaces to `/ops`, `/runtime`, or docs.
- Avoid importing duplicate archive material into source folders.
- Keep static fallback viable after major UI changes.
