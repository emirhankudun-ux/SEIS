# SEIS ADR Template

Use this template when a change affects architecture, governance, platform boundaries, agent behavior, security, release readiness, or long-term maintainability.

```markdown
# ADR-XXXX: Title

## Status

Proposed | Accepted | Superseded

## Context

What problem, constraint, or ecosystem pressure led to this decision?

## Decision

What decision is being made?

## Consequences

What improves, what becomes harder, and what must be watched?

## Security

What security, privacy, secret-safety, or permission impact exists?

## AI Policy

What agent, autonomy, tool-boundary, validation-duty, or learning-system impact exists?

## Validation

Which commands or evidence prove the decision is safely implemented?

## Rollback

How can this decision be reversed or superseded?
```

## Rule

Do not use ADRs as decoration. An ADR must explain a real decision and the tradeoff it introduces.
