# SEIS Master Prompt GitHub Controls

This document describes the GitHub branch protection settings, Required status checks, CODEOWNERS review, and readiness claim controls that support the SEIS Master Prompt.

The source manifest is data/seis-master-prompt-github-controls.json.

## Controls

- GitHub branch protection settings should protect main from accidental direct change.
- Required status checks should include Master Prompt governance, objective coverage, operational tracker, security, and open-source governance gates.
- CODEOWNERS review should cover Master Prompt, Supreme Vision, governance data, plugin skills, workflows, generated reports, SSH hardening, and deployment guidance.
- Do not claim these controls are active unless GitHub settings or current check runs have been verified.
