# SEIS Design Agency Kit

## Purpose

The SEIS Design Agency Kit turns `@seis-design` into a public-safe,
agency-grade creative production lane for founders, designers, and small teams
that need stronger briefs, identity direction, campaign structure, web
composition, and handoff discipline before paying for a full agency engagement.
It also includes a client discovery intake matrix, brand and offer naming matrix, proposal scope worksheet, agency quote comparator, agency cost control matrix, design sprint timeline matrix,
brand strategy workshop matrix, competitive positioning matrix, typography pairing and hierarchy matrix,
brand voice and messaging matrix, color system accessibility matrix, brand rationale deck, visual reference moodboard, creative asset shot list matrix, logo concept evaluation matrix,
brand usage guideline, landing page blueprint matrix, creative director QA board, revision
plan, client feedback triage board, case study layout board, production file manifest, asset size spec
sheet, print production readiness matrix, social content calendar matrix, visual QA evidence ledger, and client approval packet plus a
client-ready export index so vague agency estimates can be turned into a
reviewable work package before anyone commits budget.

It is a no-key system. It does not require API keys, live providers, client
credentials, paid media accounts, private assets, SSH, deployment, or GitHub
write access to validate the current foundation.

This is not a guaranteed replacement for every professional designer. It is a
repeatable design-production operating layer that helps SEIS reduce
agency-dependency by making briefs, brand systems, brand usage rules, campaign
kits, provenance checks, and client handoff evidence reproducible.

## What It Is Not

- Not a live client services marketplace.
- Not an automated logo generator.
- Not a paid media buying system.
- Not a trademark clearance service.
- Not a production print vendor.
- Not a platform spec guarantee.
- Not a guaranteed cost saving.
- Not fabricated evidence, including screenshot, viewport, or review evidence.
- Not a persuasion guarantee.
- Not a downloadable archive.
- Not a trademark license.
- Not a stakeholder consensus guarantee.
- Not a verified customer case study.
- Not licensed asset approval, stock-library clearance, or permission to
  publish unverified reference material.
- Not final logo approval or trademark clearance.
- Not market research, competitor legal advice, or proof of market demand.
- Not legal copy approval, compliance review, or an advertising performance
  guarantee.
- Not a font license, typeface ownership claim, or permission to use paid fonts
  without review.
- Not accessibility certification or a substitute for human accessibility
  review.
- Not print proof approval, a color guarantee, or permission to send files to
  paid production without vendor review.
- Not social media scheduling, automatic posting, or an audience growth
  guarantee.
- Not model release approval, location release approval, or permission to
  publish unverified people, product, or location imagery.
- Not a binding quote, invoice, legal recommendation, or guaranteed cost saving.
- Not a business strategy guarantee, investor advice, or board-level strategy
  approval.
- Not a client contract, legal onboarding flow, or private asset storage system.
- Not a brand name clearance, trademark opinion, domain registration, or final
  naming approval.
- Not a conversion guarantee, search ranking guarantee, or legal copy approval
  for published landing pages.
- Not procurement advice, tax advice, or a purchasing recommendation.
- Not a delivery date guarantee, project management service, or client approval.
- Not permission to publish unreviewed client work or unclear assets.

| Usage | Brand usage guideline for logo spacing, color use, type hierarchy, imagery rules, do/don't examples, accessibility, misuse boundaries, and escalation owner. | Guideline is marked not a trademark license or legal clearance. |
| Web | Landing, portfolio, case-study, or showcase direction using current no-key web surfaces. | Demo route remains no-key and no live claim is added. |
| Landing blueprint | Landing page blueprint matrix with hero promise, section order, proof blocks, objection handling, CTA ladder, responsive priority, accessibility notes, analytics questions, owner, and next review action. | Matrix is marked not a conversion guarantee, not a search ranking guarantee, and not legal copy approval. |
| Portfolio | Case study layout with context, challenge, response, proof, accessibility, quality path, CTA, and handoff sections. | Case study is marked not a verified customer case study. |
| Campaign | Social, banner, caption, CTA, story, presentation direction, and content calendar cadence for human review. | Copy, visual direction, and calendar entries are marked draft until approved and not social media scheduling. |
| Review | Creative director QA for clarity, hierarchy, contrast, consistency, motion restraint, provenance, and publication readiness. | Decision is approve, revise, or hold before publication. |
| Revision | Decision round, polish round, acceptance owner, and no-endless-revision boundary. | Revisions stay scoped and reviewable. |
| Feedback | Client feedback triage for comment source, affected deliverable, decision fix, polish, out-of-scope request, risk, owner, and next action. | Feedback triage is marked not a stakeholder consensus guarantee. |
| Visual QA | Screenshot targets, viewport checks, accessibility notes, reviewer decision, blockers, and validation commands. | Missing browser or reviewer evidence is marked blocked, not invented. |
| Approval | Client approval packet with included assets, exclusions, known risks, owner, and next action. | No client delivery claim exists without human approval. |
| Export index | Client-ready index with included files, source paths, review state, blockers, exclusions, validation commands, and owners. | Index is not a downloadable archive or host filesystem delivery. |
| Provenance | Source, license, transformation, and approval record for each image, video, font, or external asset. | Asset provenance is required before publication. |
| Handoff | File paths, validation commands, accessibility notes, risks, rollback, and next actions. | Human review before publication is mandatory. |

## Quality Principles

- Brief before visuals.
- Strategy before decoration.
- Tokens before one-off styling.
- Accessibility before polish.
- Asset provenance before publication.
- Human review before client delivery.
- Human review before publication.

## Security Boundary

- No API keys are required.
- No client secrets are allowed.
- No private client assets belong in the public repo.
- No real SSH credentials, tokens, payment credentials, or private host details
  belong in this lane.
- Live provider calls, paid media execution, client upload portals, print
  orders, trademark/legal review, deployment, publication, GitHub push, merge,
  release, or Pages activation all require explicit human approval.
- Proposal scope estimates are planning evidence only. They are not a binding
  quote, invoice, legal recommendation, paid-media plan, or guarantee that no
  professional design review will be needed.
- Client discovery intake matrices are not a client contract, not legal
  onboarding, not private asset storage, and not permission to publish client

  clearance, not domain registration, and not permission to launch an unreviewed
