# SEIS App

Status: Product foundation

The SEIS App is the application interface for the SEIS ecosystem. It should
make SEIS visible, controllable, inspectable, and safe to operate.

## Product Mission

The app is not only chat and not only a dashboard. It is the operating
interface that exposes the SEIS AI Core, repository state, documentation,
architecture, security, roadmap, approvals, evidence, release readiness, and
public readiness.

## Current Evidence

- `apps/seis-core` contains the current local-first Command Center shell.
- `docs/architecture/seis-command-center.md` documents its architecture.
- `docs/product/*` defines the next product contracts added by this foundation
  pass.

## Core Modules

- dashboard
- AI chat interface
- repository center
- documentation hub
- roadmap center
- architecture center
- security center
- AI Core center
- model router view
- prompt engine view
- agent task center
- approval center
- evidence locker
- release readiness center
- public readiness center
- settings center
- local/cloud workspace status
- plugin/tool registry view

## Non-Goals

- no fake controls
- no fake provider status
- no unapproved live actions
- no provider keys in browser code
- no deployment, SSH, or GitHub write action without approval
