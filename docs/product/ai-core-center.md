# AI Core Center

Status: Product foundation

AI Core Center is the Command Center area for inspecting and operating SEIS AI
Core safely.

## Views

- model router
- prompt engine
- agent runtime
- tool registry
- evaluation lab
- context and memory boundary
- provider privacy modes
- local model status
- audit events

## Display Requirements

Each item should show:

- status
- maturity
- evidence link
- privacy mode
- approval state
- validation state
- next action

## Current Boundary

AI Core Center may display planned or fixture-backed states. It must not claim
live provider connections, training runs, or benchmark results without evidence.
