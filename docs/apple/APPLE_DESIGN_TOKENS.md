# Apple Design Tokens

SEIS Apple-native design tokens should support a calm, cinematic,
professional workspace.

## Color Roles

| Role | Direction |
| --- | --- |
| Canvas | deep black |
| Surface | graphite / charcoal |
| Text | off-white and warm gray |
| Accent | electric cyan for precise action |
| Secondary Accent | soft violet |
| Warning | amber/orange |
| Healthy | green |
| Critical | red only for critical warnings |

## Shape and Spacing

- Prefer restrained radii.
- Keep toolbar and sidebar spacing predictable.
- Use cards for repeated items and inspectors, not every section.
- Give module grids stable dimensions.

## Typography

Use hierarchy before decoration:

- title for surface identity
- headline for selected module
- body for descriptions
- caption for metadata
- monospaced text only for commands, paths, hashes, and diagnostics

## Status Language

Status should be explicit:

- planned
- scaffolded
- demo
- implemented
- blocked
- requires review
