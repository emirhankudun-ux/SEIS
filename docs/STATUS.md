# SEIS Status

## AGI GitHub Readiness

Status: blocked pending independent evidence.

SEIS currently supports Local Demo review without provider keys. The 20B
16GB+ target is an evaluation plan, not a verified runtime. The 70B lane is
research-only, and all 512B, foundation-model, and real-AGI claims remain
blocked.

The current local validation path is:

    npm run check:seis-ai-github-readiness-chain

Passing this command confirms the claim boundary and evidence ledger structure.
It does not confirm a model download, inference run, training run, benchmark,
fresh clone, deployment, SSH connection, provider access, or external review.

GitHub Actions runs the same local-only chain with read-only repository
permissions for this readiness package.
