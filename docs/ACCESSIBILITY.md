# SEIS Accessibility

Status: non-negotiable product requirement

## Interaction

Every interactive control has an accessible name, logical focus order, visible
focus, keyboard operation where applicable, and a practical touch target.
Icon-first interfaces must remain understandable without visual inference.

## Perception

Maintain sufficient contrast, readable hierarchy, scalable text, and state
communication that does not depend on color alone. Screen-reader output must
describe purpose and state without decorative noise.

## Motion

Respect reduced-motion preferences. Motion cannot be required to understand
navigation, progress, errors, or completion.

## Validation

UI PRs document automated scans, source/token checks, keyboard and screen-reader
review when available, affected platforms, known gaps, and rollback.
