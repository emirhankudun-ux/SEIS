# SEIS Universe Research

Status: Future research direction

SEIS Universe is the long-term research path for SEIS-owned model work. It is
not an already trained model and must not be described as one.

## Research Scope

SEIS Universe may later include:

- dataset intake and provenance
- synthetic data governance
- tokenizer research
- small local model experiments
- fine-tuning experiments
- LoRA or adapter experiments
- evaluation benchmarks
- contamination control
- model cards
- checkpoint governance
- safety evaluation
- release governance

## Required Evidence For Ownership Claims

A SEIS-owned model claim requires:

- architecture specification
- tokenizer strategy
- model configuration
- training pipeline
- dataset manifest and provenance
- training logs
- checkpoints
- evaluation report
- model card
- safety review
- release governance decision

## Current Boundary

The current SEIS AI Core foundation is an LLM-powered application layer. It
does not prove SEIS-owned trained model weights.
