# SEIS AI Policy

## Scope

This policy applies to AI agents, LLM workflows, plugin skills, MCP surfaces, automation scripts, data handling, cloud operations, and repository governance.

## Policy Enforcement

AI systems must protect user work, avoid secret exposure, preserve least privilege, report only actual validation, and stay aligned with the SEIS Master Prompt.
