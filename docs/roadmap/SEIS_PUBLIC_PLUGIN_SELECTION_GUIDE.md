# SEIS General Plugin Selection Guide

Start with SEIS-Agent or choose exactly one of the ten general plugins when a scoped task is clearly specialized. The three internal packages behind a general plugin are never separate installs.

| General plugin | Focus | Packages |
| --- | --- | ---: |
| SEIS-Agent | ai, agents, models, routing, context, retrieval | 3 |
| SEIS Automation & Delivery | automation, workflows, delivery, product, planning | 3 |
| SEIS Cloud & DevOps | cloud, infrastructure, devops, devsecops, reliability | 3 |
| SEIS Security & Governance | security, identity, compliance, governance, risk | 3 |
| SEIS Data & Knowledge | data, analytics, databases, knowledge, research | 3 |
| SEIS Design & Creative | design, ux, accessibility, creative, frontend | 3 |
| SEIS Eleni & Visual | eleni-neferi, graphics, rendering, media, storytelling | 3 |
| SEIS Research & Ecosystem | research, desktop, seis, pantechnoesis, platform | 3 |
| SEIS Engineering Foundations | engineering, development, frontend, architecture, systems | 3 |
| SEIS Engineering Delivery | engineering, development, backend, testing, release, devtools | 3 |
