## Rules

- The Omega record is a planning and coverage artifact, not runtime proof.
- Planned phases must not be presented as implemented.
- Documented phases require evidence before being promoted to validated.
- Autonomous agents remain bounded by human governance, single-writer policy,
  least context, approval gates, and validation commands.
- SSH, deployment, provider calls, model training, benchmark runs, and secret
  access remain blocked unless explicitly approved and audited.
- Personal OS and learning features require privacy, consent, and memory
  boundary policies before implementation.

## Evidence Requirements

Before any phase can move beyond planned or documented, it needs:

- A source record under `content/development/` or an official doc under `docs/`.
- A clear next safe action.
- A validation command or review gate.
- A security and privacy boundary.
- Explicit current-vs-planned language.
- No fake runtime, provider, deployment, model, or benchmark claims.
