# SEIS Sovereign Product Track

## Decision

SEIS remains an independent Apple-first creative engineering operating system. It owns its platform runtime, supervised AI orchestration, workspaces, tool permissions, Apple-native direction, security, plugins, and release evidence.

It does not become the owner of Eleni-Neferi creative memory, Pantechnoepistemonoesis research programs, or PANTECHNOSYNI synthesis identity. Related projects may interoperate through reviewed contracts while their repositories and product decisions remain canonical.

## Machine-readable contract

`content/development/seis-sovereign-product-track.json` records:

- immutable SEIS identity and repository ownership;
- eight owned product domains;
- explicit non-ownership boundaries for three sibling products;
- current delivery tracks and evidence paths;
- contract-only interoperability;
- Apple-first, Swift-first-when-native, human-approved truth boundaries.

## Read-only interface

```bash
node scripts/seis-sovereign-track.mjs summary
node scripts/seis-sovereign-track.mjs domains
node scripts/seis-sovereign-track.mjs tracks
node scripts/seis-sovereign-track.mjs boundaries
node scripts/seis-sovereign-track.mjs json
```

## Validation

```bash
node --test test/seis-sovereign-product-track.test.mjs
node scripts/check-seis-sovereign-product-track.mjs
npm run check:ecosystem-foundation
```

The focused checker rejects identity drift, umbrella ownership, source-code import, cross-repository writes, runtime-authority transfer, live-provider claims, unsafe evidence paths, and sensitive-shaped fields.

## Next product work

The next SEIS PR should deepen one SEIS-owned vertical slice—Desktop/workspaces, AI Core/routing, Apple-native contracts, or security/plugin delivery—without adding sibling product responsibilities.
